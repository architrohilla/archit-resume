# Archit Rohilla — HTML Resume

## Files

- `index.html` — **main file to edit resume content**
- `style.css` — layout, typography, colors and print styling

## Run locally

Open `index.html` directly in a browser.

For a better development experience, use VS Code with a local server / Live Server extension.

## Generate PDF manually

Open the resume in Chrome/Edge and use **Print → Save as PDF**.

The CSS includes an A4 print layout.
